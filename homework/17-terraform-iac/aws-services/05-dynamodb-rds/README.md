## 1. DynamoDB (NoSQL)

- **What is DynamoDB?** Fully managed, serverless NoSQL database service delivering single-digit millisecond performance.
- **Key Elements:**
  - *Tables*: Collection of items.
  - *Items*: Collection of attributes (similar to rows).
  - *Attributes*: Key-value pairs.
  - *Partition Key*: Primary key attribute used for data distribution.
  - *Sort Key*: Optional second key for ordering partition data.
- **Use Cases:** Gaming leaderboards, real-time user profiles, shopping carts.

---

## 2. RDS (Relational Database Service)

- **What is RDS?** Managed relational database service that makes it easy to set up, operate, and scale databases in the cloud.
- **Supported Engines:** PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, Amazon Aurora.
- **Features:**
  - *Multi-AZ*: High-availability synchronous replication across Availability Zones.
  - *Read Replicas*: Asynchronous copies for offloading read traffic.
  - *Automated Backups & Snapshots*: Point-in-time recovery.
  - *Security*: IAM database authentication, KMS encryption, VPC isolation.
